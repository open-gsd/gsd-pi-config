## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tag gaps, underline offset, micro padding |
| sm | 8px | Inline control gaps, list meta stack |
| md | 16px | Default element spacing, header horizontal pad (mobile) |
| lg | 24px | Section gaps inside pages (`space-y-6` ≈ 24) |
| xl | 32px | Page horizontal pad at `sm+`, major block gaps |
| 2xl | 48px | Start panel vertical breathing (`py-12`) |
| 3xl | 64px | Rare page-level top/bottom only if needed |

### Layout constants (locked)

| Constant | Value | Notes |
|----------|-------|-------|
| Shell nav height | **56px** (`3.5rem`) | D-04 — do not compress to 44px |
| Editor workspace strip | **36px** (`2.25rem`) | Keep; strip content restyle is light only (empty start is in scope; loaded toolbar Phase 4) |
| Page max width (gallery) | `max-w-3xl` (48rem) | Linear list reading width |
| Page max width (wizard / start) | `max-w-lg` (32rem) | Focused single column |
| Page pad | `px-4 py-8` → `sm:px-6` | 16 / 32 vertical, 16→24 horizontal |
| List row pad | `p-4` → `sm:p-5` (16 / 20) | 20px is intentional exception for row density (see Exceptions) |
| Control min height | **40px** | Interactive controls on restyled surfaces |
| BrandMark image (header) | **32px** (`h-8 w-8`) | Keep PNG; no flat-square replacement (D-03) |

### Exceptions

- **List row vertical pad 20px at `sm+`** (`p-5`) — not on 8-pt scale; allowed for row readability between 16 and 24.
- **Header controls may sit at 40px inside 56px bar** with vertical centering; do not grow bar.
- **Tag chips** use **4px** vertical pad (`py-1`) only — compact meta, not primary hit targets; never 2px.

## Typography

Exactly four sizes, two weights.

| Role | Size | Weight | Line height | Usage |
|------|------|--------|-------------|-------|
| Body | **14px** (`text-sm`) | 400 | 1.5 | Page intros, list descriptions, OAuth status, start step body |
| Label / meta | **12px** (`text-xs`) | 400 or 600 | 1.25 | Section labels (uppercase), tags, author line, theme/nav text, kicker |
| Heading | **20px** (`text-xl`) | 600 | 1.2 | Page titles: Gallery, Wizard |
| Display | **24px** (`text-2xl`) | 600 | 1.2 | Start panel H1 only |

**Weights locked:** 400 (regular) + 600 (semibold). Do not introduce 500 medium as a third system weight; if Base UI Button defaults to medium, override to 500 only inside Button (component exception) or map Button to 600 for primary emphasis — prefer **500 only on Button**, body/heading stay 400/600.

### Type rules

| Element | Spec |
|---------|------|
| Page title | Heading 20px / 600 / tracking tight; color `--foreground` |
| Start H1 | Display 24px / 600 |
| Section label | 12px / 600 / uppercase / `tracking-wider` / `--muted-foreground` |
| Kicker | **12px** (Label role) / 600 / uppercase / `tracking-[0.2em]` / **primary** (not logo cyan) — never 10px or 11px |
| Nav link | 12px / 600 when active, 400 or 600 idle muted |
| Mono meta | Geist Mono **12px** (Label role) / 400 / `--muted-foreground` (author, paths, `~/.gsd/`) — never 10px or 11px |
| Links in body | Primary color; underline on hover; no neon cyan |

## Color

Source of truth: `.planning/design/PALETTE.md` (Mist Sky).  
**Do not** use logo cyan `#22d3ee` / purple `#a855f7` as primary or accent on web (palette supersedes `.agents/context/DESIGN.md` for this milestone).

### 60 / 30 / 10 split

| Role | Dark | Light | Usage share |
|------|------|-------|-------------|
| Dominant (60%) | `#0b0c0e` → `--background` | `#f5f7fa` | Page canvas, header base |
| Secondary (30%) | `#111316` → `--card` | `#ffffff` | Elevated panels, list surface, subtle strips |
| Subtle fill | `#181b20` → `--muted` / `--secondary` / hover wash | `#eef1f5` | Row hover, segment hover |
| Accent (10%) | `#a8c5e8` → `--primary` | `#5a7fa8` | **Reserved list below only** |
| On primary | `#0b0c0e` | `#f5f7fa` | Text/icons on filled primary buttons |
| Border | `#2a2e36` | `#d8dee8` | 1px rules, dividers, inputs |
| Foreground | `#f2f4f7` | `#14171c` | Body text |
| Muted text | `#8b929e` | `#5c6570` | Secondary copy, idle nav |
| Destructive (soft) | `#e8b4b0` | `#b85c56` | Soft danger outline + error text only |
| Soft primary wash | `rgba(168, 197, 232, 0.12)` | `rgba(90, 127, 168, 0.1)` | Active choice row fill, active nav wash if needed |
| Primary hover | `#c4daf2` | `#4a6d94` | Filled primary hover |
| Ring | primary @ ~35% dark / ~25% light | Focus rings |

### Accent reserved exclusively for

1. Primary filled buttons (Use preset, Create/Open editor, Import files, Create new preset)
2. Focus rings (`--ring`)
3. Active nav **underline** (1px bottom rule in primary)
4. Active theme option underline or small primary bottom rule
5. Active wizard choice **left-edge** bar (2–3px) + optional soft wash
6. Start panel kicker text (“Git · Ship · Done”)
7. Inline text links that are primary actions (browse gallery, PR link on OAuth success)
8. Workspace label mono accent in editor strip (when shown) — Mist Sky primary, not cyan

**Not for:** decorative backgrounds, multi-color tags, solid danger fills, gradients, glass glows.

### Token cutover (implementation order D-21)

1. Replace Phase 1 neutral OKLCH in `src/index.web.css` with Mist Sky hex (or equivalent OKLCH) under `:root` (light) and `.dark` (dark default product).
2. Set `--radius: 0`.
3. Remap `--color-gsd-*` bridge to Mist Sky semantic tokens so unrestyled editor/forms do not flash logo cyan:
   - `--color-gsd-accent` → `--primary` (retire `--bridge-accent` cyan)
   - `--color-gsd-danger` → `--destructive`
4. Keep bridge classes for **unrestyled** editor/forms until Phase 4; **drop `gsd-btn` usage** on Phase 2 surfaces (D-22).

### Explicit non-colors

| Forbidden | Why |
|-----------|-----|
| `#22d3ee`, `#38e0ff`, `#0891b2` as primary/accent | Logo / old bridge cyan |
| `#a855f7` | Logo purple |
| Solid red filled destructive buttons | D-07 soft danger outline only |
| Glass / backdrop-blur heavy chrome | Linear flat grammar; header may stay simple solid/opaque |
| Gradient text | Anti-pattern |

## Button language (WEB-06)

On every surface Phase 2 restyles, **only** `Button` from `@/components/ui/button` (or `buttonVariants` + link semantics). No `gsd-btn` / `btn` / `btnPrimary` from `uiClasses` on those surfaces.

| Role | Variant | Visual | Used for |
|------|---------|--------|----------|
| Primary | `default` | Filled `--primary` / `--primary-foreground`; hover primary-hover | Use preset, Open editor, Import files, Create new preset |
| Secondary | `outline` | 1px `--border`, transparent/bg surface, foreground on hover muted wash | Preview, Refresh list, Load preset, New preset (start), Skip (blank), Submit via PR, opengsd.net |
| Destructive | soft outline | 1px soft rose border + `--destructive` text; transparent fill; hover soft wash — **not** solid red | Destructive actions if any appear on these routes (none primary this phase; reserve for future cancel-with-loss) |
| Ghost / link | `ghost` or `link` | Text-only; optional | Header external link if not outline; OAuth “Back to editor” |

### Button sizes on Phase 2 surfaces

| Context | Size | Min height |
|---------|------|------------|
| Page CTAs | `default` or `lg` | ≥40px (override h-8 → min-h-10 if needed) |
| Row actions (gallery) | `default` / `sm` if dense but **≥40px hit target** | 40px |
| Full-width mobile primary (wizard Create) | `default` + `w-full` below `sm` | 40px |

Disabled: opacity 50%, `pointer-events-none`; loading label swap (e.g. “Loading…”) allowed.

## Interaction & motion

| Concern | Spec |
|---------|------|
| Motion duration | 150–200ms ease-out on color/border only |
| Page load choreography | None |
| Active press scale | Prefer none (linear); if kept, respect `prefers-reduced-motion` |
| Focus | Visible ring using `--ring` (primary-tinted); never remove focus styles |
| Disabled | opacity 0.5; no hover lift |
| Loading buttons | Disable + label “Loading…”; do not spinner-bomb every row |

## Accessibility & hit targets (ISO-04 prep)

| Rule | Spec |
|------|------|
| Min control height | **40px** for buttons, nav items, theme radios, search, choice rows (≥48px for choice rows) |
| Theme toggle | `role="radiogroup"` + `role="radio"` + `aria-checked` (keep) |
| Main nav | `<nav aria-label="Main">` |
| Errors | `role="alert"` |
| Labels | Wizard inputs have visible labels (not placeholder-only) |
| Search | `type="search"` + accessible name (label or `aria-label="Search presets"`) |
| Focus order | Header brand → nav → theme → external → main content |
| Contrast | Primary on dark is light sky on near-black; primary on light is deeper sky — do not invert incorrectly |
