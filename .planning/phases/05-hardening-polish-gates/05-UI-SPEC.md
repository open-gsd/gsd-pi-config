| 2xl | 48px | Not primary this phase |
| 3xl | 64px | Not used |

### Layout constants (locked — carry forward)

| Constant | Value | Notes |
|----------|-------|-------|
| Control min height | **40px** | All residual buttons, search, key row actions, segment filters if restyled on web |

## Accessibility checklist (ISO-04 acceptance)

Audit + fix gaps on **web residual + prior restyled surfaces**. Prefer a11y over pure cosmetics (D-12). **No axe CI** this phase.

### Must pass (checklist)

| # | Check | Acceptance |
|---|-------|------------|
| A1 | **Hit targets ≥40px** | Buttons, nav items, theme radios, toolbar, residual key actions, provider actions |
| A2 | **Visible focus-visible** | Mist Sky `--ring` (primary-tinted); never bare `outline-none` without ring replacement |

| A4 | **Invalid states** | Field `data-invalid` + visible error text preserved; residual collision text visible |

| A8 | **Contrast** | Mist Sky pairs; soft destructive text on dark/light readable |
| A9 | **Switch/toggle** | `role="switch"` + `aria-checked` where used (FormControls) |
| A10 | **No keyboard trap** | Residual custom panels (if any) do not trap without ESC/Tab exit |
