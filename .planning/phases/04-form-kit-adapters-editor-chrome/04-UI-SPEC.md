## Spacing Scale

**Inherited from Phase 2/3** (multiples of 4 only). Do not invent a second scale.

| Token | Value | Usage (Phase 4) |
|-------|-------|-----------------|
| xs | 4px | Chip gaps, switch thumb inset, icon/reorder gaps, dirty-dot margin |
| sm | 8px | Toolbar control gap, field control internal gaps, ModelChain row gaps |
| md | 16px | Field row pad (`py-3`–`py-4` region), sidebar item pad, main content pad mobile |
| lg | 24px | Section stack gaps, main `sm:px-6` rhythm |
| xl | 32px | Rare outer breathing |
| 2xl | 48px | Not primary this phase |
| 3xl | 64px | Not used |

### Layout constants (locked)

| Constant | Value | Notes |
|----------|-------|-------|
| Sidebar width | **224px** (`w-56`) | Keep current |
| Sidebar item min height | **40px** | Linear nav row |
| Toolbar height | content-driven; controls **≥40px** | Wrap allowed; gap-2 (8px) |
| Control min height | **40px** | Inputs, selects, switches hit area, toolbar buttons, multi triggers |
| Field control width (sm+) | **208px** (`w-52`) text/select; **256px** (`w-64`) multi/model | Match current FormControls widths |
| Field row gap | **12–16px** label↔control (`gap-3` / `sm:gap-4`) | Between md scale steps — see Exceptions |
| Chip pad | **4px × 8px** (`py-1 px-2`) | Compact meta; not primary hit target |
| Switch track | **20×36** visual (`h-5 w-9`); outer hit **≥40×40** | Keep product toggle proportions |
| Left-edge active | **2–3px** primary | Sidebar active; multi-select checked row optional wash |
| Dirty section dot | **6px** (`h-1.5 w-1.5`) | Primary fill; not a second accent system |
| Mobile drawer scrim | `bg-black/50` | Keep `useSidebarDrawerLayout` behavior; restyle panel only (D-16) |
| Main content pad | `px-4 py-4` → `sm:px-6 sm:py-5` | Keep rhythm |

### Exceptions

- **Field row vertical pad 12px** (`py-3`) — between 8 and 16; intentional form density (matches current Field).
- **Field horizontal gap 12px** (`gap-3`) on stacked mobile — same rationale.
- **Chip / tag vertical pad 4px** — compact meta only; remove control still needs ≥24px hit if tiny, prefer 24–32px remove button hit with visual ×.
- **No 44px icon-only exception** — 40px min remains the floor (Phase 2/3).
- **20px horizontal pad** only if reusing modal density patterns; editor shell uses 16→24.

## Button language (WEB-06 — editor chrome)

On **web** restyled toolbar and form actions that are true buttons, **only** `Button` from `@/components/ui/button` (or `buttonVariants`). Drop `btn` / `btnPrimary` / `gsd-btn` on those web surfaces (D-00b, Phase 2 D-22 completion for editor chrome).

| Role | Variant | Used for |
|------|---------|----------|
| Primary | `default` (filled primary) | **Save** when dirty (desktop) / **Download** when workspace ready (web) |
| Secondary | `outline` | Import, Load preset, Share, Export, Submit, Sections (mobile), Discard |
| Destructive | soft `destructive` | **Discard** may use outline secondary (preferred) — not solid red; true destructive confirm **not required** this phase |
| Ghost | `ghost` | Quiet icon-only (ModelChain × / ↑↓ if buttonized), banner dismiss |

### Toolbar CTA rules (D-14, FRM-04)

| State | Save/Download visual |
|-------|----------------------|
| Dirty (desktop) or workspace ready (web) and not needsProject | Primary filled; enabled (subject to existing disabled rules) |
| Clean desktop / not ready web / needs project / saving gate | Disabled outline/muted — **same enablement logic as today** |
| Saving | Disabled + label **Saving…** / **Downloading…** |
| Saved flash | Label **Saved** / **Saved N change(s)** / **Downloaded** — quiet; no toast |

**FRM-04 hard constraint:** Do not change when dirty is true, what Save writes, Download packaging, Import/Load/Share handlers, or scope selection semantics — presentation only.
