## Spacing Scale

**Inherited from Phase 2** (multiples of 4 only). Do not invent a second scale.

| Token | Value | Usage (Phase 3) |
|-------|-------|-----------------|
| xs | 4px | Icon/close gaps, tag gaps, mono meta |
| sm | 8px | Footer button gap, inline control gaps |
| md | 16px | Default body pad (`px-4`), list row pad |
| lg | 24px | Dialog header/body vertical rhythm (`py-4` + gap-6 stacks) |
| xl | 32px | Rare outer breathing only |
| 2xl | 48px | Palette top offset (`pt-12` ≈ 48) for top-ish placement |
| 3xl | 64px | Not used in overlays |

### Overlay layout constants (locked)

| Constant | Value | Notes |
|----------|-------|-------|
| Scrim | `bg-black/60` (~60% opacity) | D-03 — soft dark; **no heavy blur** on product modals (palette may drop current `backdrop-blur-sm`) |
| Dialog max width (share / preview) | `max-w-2xl` (42rem) | Review pane needs width |
| Dialog max width (import / load / submit) | `max-w-md` → `max-w-lg` | Import `max-w-md`; Load/Submit `max-w-lg` |
| Dialog max height | `max-h-[80vh]` share/preview; Load `max-h-[85vh]` | Body scrolls inside |
| Dialog outer pad | `p-4` (16px) | Viewport inset |
| Header pad | `px-5 py-4` (20×16) | 20px horizontal is intentional density exception (see Exceptions) |
| Body pad | `px-5 py-4` | |
| Footer pad | `px-5 py-3` (20×12) | Footer slightly tighter vertically |
| Footer gap | `gap-2` (8px) | Between Cancel / primary |
| Control min height | **40px** | Buttons, search, file rows, palette rows |
| Palette max width | `max-w-xl` (36rem) | Match current |
| Palette list max height | `max-h-96` (24rem) | Discretion locked — no virtualization unless >50 visible lag |
| Close control | **40×40** min hit | Icon button size |

### Exceptions

- **Header/body horizontal pad 20px** (`px-5`) — not on strict 8-pt steps; allowed for modal density between 16 and 24 (same rationale as Phase 2 list `p-5`).
- **Footer vertical pad 12px** (`py-3`) — compact action bar; still ≥40px buttons.
- **Palette top offset 48–96px** — prefer `pt-12` (48) or keep current `pt-24` (96) feel; pick **one**: default **`pt-24`** to preserve D-09 “top-ish” muscle memory.
- **No 44px icon-only exception** beyond 40px min — close and icon buttons use 40px.

## Typography

Exactly four sizes, two system weights — **same as Phase 2**.

| Role | Size | Weight | Line height | Overlay usage |
|------|------|--------|-------------|---------------|
| Body | **14px** (`text-sm`) | 400 | 1.5 | Dialog titles may use 14/600; intro prose; palette rows; form values |
| Label / meta | **12px** (`text-xs`) | 400 or 600 | 1.25 | Dialog descriptions, file labels, alerts, palette hints, footer kbd strip |
| Heading | **20px** (`text-xl`) | 600 | 1.2 | **Not used inside overlays** this phase (page titles only) |
| Display | **24px** (`text-2xl`) | 600 | 1.2 | **Not used inside overlays** |

**Weights locked:** 400 + 600. Button may use component medium (500) only inside `Button` (Phase 2 exception).

### Type rules (overlays)

| Element | Spec |
|---------|------|
| Dialog title | Body role **14px / 600** / `--foreground` — not 20px page heading |
| Dialog description | Label **12px / 400** / `--muted-foreground`; `code` at 12px mono (never 10px system type) |
| Review mono block | Geist Mono **12px / 400** / `--foreground` on `--background` (or muted surface) |
| Palette input | Body 14px / 400; placeholder muted |
| Palette row primary | 14px / 600 label |
| Palette row meta | 12px / 400 muted; mono for path |
| Palette empty | 12px / 400 muted, centered, quiet |
| Palette footer strip | 12px / 400 muted (never 10px) |
| Inline error | 12px / 400 / soft destructive; `role="alert"` |
| Kicker / required marker | 12px; required uses **primary** text (“required”), optional uses muted |

**Type cleanup vs legacy:** Replace `text-[10px]` / `text-[11px]` on restyled overlays with **12px Label** role so Phase 2 type contract holds.

## Button language (WEB-06 — overlays)

On every Phase 3 restyled overlay, **only** `Button` from `@/components/ui/button` (or `buttonVariants`). **No** `btn` / `btnPrimary` / `gsd-btn` from `uiClasses` on those surfaces.

| Role | Variant | Used for |
|------|---------|----------|
| Primary | `default` (filled primary) | Copy to clipboard, Import into editor/workspace, Sign in with GitHub, Done |
| Secondary | `outline` | Cancel, Browse…, From file…, close-adjacent secondary |
| Destructive | soft `destructive` (outline/soft wash — not solid red) | Only if a true destructive confirm appears; **none required as primary CTA this phase** |
| Ghost | `ghost` | Dialog close (X); quiet icon-only |

### Sizes

| Context | Size | Min height |
|---------|------|------------|
| Dialog footer CTAs | `default` | ≥40px |
| Browse / From file row actions | `default` or `sm` with min-h-10 | ≥40px |
| Close X | `icon` or ghost icon 40×40 | 40px |

Disabled: opacity 50%; loading label swap (“Importing…”, “Submitting…”, “Copied!”).

## Dialog anatomy (OVL-01)

### Shell (all product modals)

| Piece | Contract |
|-------|----------|
| Primitive | shadcn **Dialog** (centered) — D-01 |
| Placement | Centered in viewport (`items-center justify-center`) |
| Scrim | `black/60`; click dismisses (D-04) unless disabled mid-flight (see Focus) |
| Panel | `--card` / popover surface; 1px border; radius 0; flex column; overflow hidden |
| Structure | **Header** (title + description + close) → **Body** (scroll) → **Footer** (actions) preferred; linear equivalent OK (discretion) |
| Close | Visible **X** control + **ESC** + **backdrop click** (D-04) |
| Title | `DialogTitle` (or equivalent a11y) — 14px/600 |
| Description | `DialogDescription` when helpful — 12px muted |
| Focus | Trap inside Dialog; restore trigger focus on close (D-13, D-14, OVL-03) |
| Nesting | **No nested Dialogs** (D-15). Select/listbox **inside** Dialog is OK (Phase 4). |
| Exclusivity | **Single open overlay** — opening palette closes modal and vice versa (D-16) |

### AlertDialog

| Rule | Spec |
|------|------|
| Use when | True confirm / destructive only (D-02) |
| Do not use | Share review, Import form, Load list, Submit form, Palette |
| Phase 3 reality | **No mandatory destructive confirm flow** in current product modals; install AlertDialog **only if** implementation introduces a confirm step — otherwise defer install to keep FND-03 tight |

## Focus, ESC, exclusivity (OVL-03)

| Concern | Spec |
|---------|------|
| Focus trap | Provided by shadcn/Base UI Dialog — remove redundant window Escape listeners where Dialog owns dismiss (D-13) |
| Focus restore | Return focus to opener control on close (D-14) |
| ESC | Closes active overlay |
| Backdrop click | Closes overlay (D-04) |
| Busy / mid-OAuth handoff | Discretion: while `busy` on Import, disable primary only; **keep ESC/backdrop** unless data-loss risk is proven. Submit navigates away on OAuth — no special nest. |
| Nested Dialog | **Forbidden** (D-15) |
| Palette vs modal | **Exclusive** — one open at a time (D-16); host (`ConfigApp` / pages) enforces |
| Select inside Dialog | Allowed later; do not break Dialog focus scope (OVL-03) |
| Initial focus | Dialog: first focusable or title per Base UI; Palette: search input; Load: search input (`autoFocus`) |
| Focus ring | `--ring` primary-tinted; never `outline-none` without visible replacement |
